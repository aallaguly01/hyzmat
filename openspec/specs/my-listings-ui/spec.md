# my-listings-ui Specification

## Purpose
Вкладка «Мои заявки» — список заявок текущего пользователя с возможностью редактировать, удалять и создавать новые.

## Layout
```
┌──────────────────────────────┐
│ Мои заявки                   │
├──────────────────────────────┤
│ ┌──────────────────────────┐ │
│ │ ПОЧТА        [Истекла]   │ │  ← бейдж типа + бейдж статуса
│ │ Ашхабад ➔ Москва         │ │
│ │ ✈ 15 окт 2026            │ │
│ │ [Редактировать] [Удалить]│ │
│ └──────────────────────────┘ │
│                              │
│                 [+ Создать]  │  ← FAB, над BottomTabs
├──────────────────────────────┤
│   📰 Лента  │  📋 Мои заявки  │
└──────────────────────────────┘
```

## Components
| Компонент | Назначение |
|---|---|
| `MyListingsPage` | Страница `/my`, запрос `GET /api/me/listings` |
| `ListingCard` (переиспользуется из feed-ui) | с `actions = ["edit", "delete"]` и бейджами типа/статуса |
| `CreateFab` | Акцентная кнопка «+ Создать заявку» |
| `EmptyState`, `ErrorState`, `CardSkeleton` | Состояния |

## Requirements

### Requirement: Список своих заявок
Страница SHALL показывать все заявки текущего пользователя обоих типов в порядке `createdAt DESC`, с бейджем типа («Почта»/«Перевод»).

#### Scenario: Есть заявки
- **WHEN** API вернул 2 заявки (MAIL и TRANSFER)
- **THEN** отображаются 2 карточки с бейджами «Почта» и «Перевод» и кнопками «Редактировать» и «Удалить»
- **AND** кнопки «Написать» на карточках нет

#### Scenario: Устаревшая заявка
- **WHEN** у заявки `isExpired = true`
- **THEN** карточка отображается приглушённой (`opacity: 0.6`) с бейджем «Истекла» и подсказкой «Не показывается в ленте. Измените дату, чтобы продлить»

#### Scenario: Нет заявок
- **WHEN** API вернул пустой список
- **THEN** `EmptyState` «У вас пока нет заявок» с кнопкой «Создать заявку»

#### Scenario: Ошибка загрузки
- **WHEN** запрос завершился ошибкой
- **THEN** `ErrorState` с кнопкой «Повторить»

### Requirement: Создание заявки (FAB)
Страница SHALL содержать фиксированную акцентную кнопку «+ Создать заявку» (фон `--tg-theme-button-color`, текст `--tg-theme-button-text-color`), расположенную над нижней панелью и не перекрывающую последнюю карточку (нижний отступ списка ≥ высоты FAB).

#### Scenario: Нажатие FAB
- **WHEN** пользователь нажимает «+ Создать заявку»
- **THEN** открывается `/listings/new`

#### Scenario: Достигнут лимит
- **WHEN** у пользователя 5 заявок
- **THEN** FAB отображается неактивной, по нажатию — `WebApp.showAlert("Можно иметь не более 5 заявок. Удалите ненужные.")`

### Requirement: Редактирование
Кнопка «Редактировать» SHALL открывать форму `/listings/:id/edit`, предзаполненную данными заявки.

#### Scenario: Открытие формы
- **WHEN** пользователь нажимает «Редактировать» на заявке `abc`
- **THEN** открывается `/listings/abc/edit` с заполненными полями (данные из кэша списка, без повторного запроса если кэш свежий)

### Requirement: Удаление
Кнопка «Удалить» SHALL запрашивать подтверждение через `WebApp.showConfirm("Удалить заявку?")` и после подтверждения удалять заявку оптимистично.

#### Scenario: Подтверждённое удаление
- **WHEN** пользователь нажимает «Удалить» и подтверждает
- **THEN** карточка сразу исчезает из списка, отправляется `DELETE /api/listings/:id`, срабатывает `HapticFeedback.notificationOccurred("success")`
- **AND** кэш ленты инвалидируется

#### Scenario: Отмена
- **WHEN** пользователь нажимает «Удалить» и отменяет
- **THEN** запрос не отправляется, карточка остаётся

#### Scenario: Ошибка удаления
- **WHEN** `DELETE` вернул ошибку (кроме `404`)
- **THEN** карточка возвращается на место, показывается `WebApp.showAlert` с `error.message`, `HapticFeedback.notificationOccurred("error")`

#### Scenario: Уже удалена
- **WHEN** `DELETE` вернул `404`
- **THEN** карточка остаётся удалённой, ошибка не показывается

#### Scenario: Повторное нажатие
- **WHEN** удаление уже выполняется
- **THEN** кнопки карточки неактивны, повторный запрос не отправляется
