## ADDED Requirements

### Requirement: Поле «Комментарий»
Форма обоих типов SHALL содержать последним необязательное поле «Комментарий» — многострочное (`<textarea>`, до 300 символов) с placeholder «Можете указать способ связи». Пустое поле не мешает публикации.

#### Scenario: Поле в форме
- **WHEN** пользователь выбрал тип «Почта» или «Перевод»
- **THEN** последним полем формы отображается «Комментарий» с placeholder «Можете указать способ связи»

#### Scenario: Публикация с комментарием
- **WHEN** пользователь заполнил обязательные поля и «Комментарий» = «WhatsApp +99365000000» и нажал «Опубликовать»
- **THEN** `POST /api/listings` содержит `comment: "WhatsApp +99365000000"`

#### Scenario: Публикация без комментария
- **WHEN** «Комментарий» пуст
- **THEN** `MainButton` активна на валидной форме, в теле `POST` нет поля `comment`

#### Scenario: Очистка при редактировании
- **WHEN** в форме редактирования заявки с комментарием пользователь очищает «Комментарий» и нажимает «Сохранить»
- **THEN** отправляется `PATCH` с телом `{ comment: null }`
