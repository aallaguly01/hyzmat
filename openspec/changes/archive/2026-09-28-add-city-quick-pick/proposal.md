# Change: Быстрый выбор города в форме заявки

## Why
Поля «Откуда»/«Куда» — свободный ввод: пользователи каждый раз печатают город вручную и по-разному
(«Ашгабат», «Ашхабад», «ашх»), из-за чего поиск по ленте находит не всё. Большинство заявок ходит
между одними и теми же городами — их удобнее выбирать одним тапом.

## What Changes
- Под каждым полем города в форме (оба типа, создание и редактирование) показываются чипсы
  популярных городов: Балкан, Ашхабад, Мары, Лебап, Дашогуз, Казань, Москва.
- Тап по чипсу подставляет город в поле; свой город по-прежнему вводится вручную.
- Чипс города, выбранного в соседнем поле, неактивен (города отправления и назначения должны различаться).
- Список — константа `POPULAR_CITIES` в `packages/shared`.

Это подсказки, а не справочник городов (он по-прежнему вне scope, см. `project.md`): контракт API,
валидация (2–64 символа) и поиск по подстроке не меняются.

## Impact
- Affected specs: `listing-form-ui`
- Affected code: `packages/shared/src/constants.ts`, `apps/web/src/shared/ui/CityChips.tsx` (новый),
  `apps/web/src/shared/ui/Controls.module.css`, `apps/web/src/shared/hooks/useZodForm.ts`,
  `apps/web/src/features/listing-form/ListingFormPage.tsx`
- API, БД, миграции — без изменений
