## ADDED Requirements

### Requirement: Просмотры заявки
Каждая заявка SHALL иметь счётчик показов `viewCount` (целое ≥ 0, у новой — `0`), который MUST присутствовать во всех ответах `Listing`. Клиент сообщает о показах через `POST /api/listings/views` с телом `{ ids: string[] }` (1–50 uuid); ответ `204`. Каждый id из пачки увеличивает счётчик на 1 (повторы в одной пачке — один раз), кроме заявок самого зрителя; несуществующие id игнорируются. Учёт просмотра MUST NOT менять `updatedAt`.

#### Scenario: Показ другому пользователю
- **WHEN** Боб отправляет `POST /api/listings/views` с id заявки Алисы дважды
- **THEN** оба ответа `204`, `viewCount` заявки = 2 в ленте и в `GET /api/me/listings`

#### Scenario: Показ автору
- **WHEN** Алиса отправляет `POST /api/listings/views` со своей заявкой
- **THEN** ответ `204`, `viewCount` не меняется

#### Scenario: Некорректное тело
- **WHEN** `ids` отсутствует, пуст, содержит не uuid или длиннее 50
- **THEN** ответ `400` с кодом `VALIDATION_ERROR`
